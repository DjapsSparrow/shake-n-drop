# Journal de Session — 2026-11-27 (Shake'n'Drop v1.0.0 → v1.0.20)

## 🎯 Objectifs & Périmètre
Créer de zéro une mini-application macOS 100 % native (Swift 6.4, SwiftUI, AppKit) reproduisant **Dropover** : étagères flottantes Liquid Glass, déclenchement *Shake-to-trigger*, raccourci global, barre de menu, Quick Look, ZIP, AirDrop, distribution GitHub Releases avec auto-updater, parcours d'installation intégré et formulaire de feedback.

## 🛠️ Modifications & Fichiers impactés
- **Logique pure (`Sources/WebodropKit/`)** : `ShakeDetector.swift`, `ShelfTypes.swift`, `ShortcutConfig.swift`, `VersionCompare.swift` + 6 tests unitaires (`WebodropKitTests.swift`).
- **Moteur & Étagères (`Sources/Webodrop/`)** :
  - `ShelfModel.swift`, `Shelf/ShelfPanel.swift`, `Shelf/ShelfDragBridge.swift`, `Shelf/ShelfView.swift` : multi-étagères flottantes `.nonactivatingPanel`, drag-in/drag-out AppKit multi-fichiers, raccourcis URL `.webloc` avec titre + favicon + ouverture au clic, bouton intelligent `⇤`/`⇥` dans l'en-tête pour ranger en languette Liquid Glass `40×96`.
  - `System/ShakeMonitor.swift`, `System/GlobalHotkey.swift`, `System/StatusBarController.swift` : Shake filtré sur vrai drag `NSPasteboard(name: .drag)`, raccourci Carbon `⌥⇧D`, menu barre d'outils épuré avec icônes SF Symbols alignées et picto 18×18 assorti.
  - `System/UpdateChecker.swift`, `UpdatePromptView.swift`, `ChangelogView.swift` : auto-updater GitHub Releases (`DjapsSparrow/shake-n-drop`), fenêtre native de nouveautés en puces, historique complet des versions depuis `v1.0.0`.
  - `OnboardingView.swift` : parcours d'installation 2 étapes (copie auto `/Applications` + Dock + animation « Bien installé ! »).
  - `FeedbackView.swift`, `System/FeedbackHelper.swift`, `docs/feedback.html` (par Pazu) : formulaire intégré via `WKWebView` + GitHub Pages + Web3Forms vers `support@webomatik.fr` avec pont JS `close`/`settings`.
  - `Icon/AppIcon.icon/` : icône Liquid Glass sur-mesure (*Curseur qui vibre* avec 2 arcs de secousse).
  - `build.sh`, `tools/make_dmg.sh`, `tools/release.sh` : build Release macOS 14+, DMG propre, flag `--no-install` pour tester les mises à jour via l'app.

## 🐛 Problèmes, Bugs & Régressions rencontrés
- **Swift 6 strict concurrency** : méthodes `QLPreviewPanelDataSource` non-isolées dans un package `defaultIsolation(MainActor.self)` → corrigé avec `nonisolated` + `MainActor.assumeIsolated`.
- **Déplacement `NSPanel` `.borderless` bloqué** : `isMovableByWindowBackground = true` insuffisant avec SwiftUI + `.glassEffect` → corrigé avec `WindowDragHandle` (`performDrag(with:)`).
- **Fenêtre Réglages inouvrable en `LSUIElement`** : scène SwiftUI `Settings` non câblée sans fenêtre principale → corrigé avec une `NSWindow` dédiée (`NSHostingController`).
- **Formsubmit bloqué par Infomaniak & Web3Forms bloqué en `curl`** : bascule sur Web3Forms client-side hébergé sur GitHub Pages (`docs/.nojekyll` requis sinon Jekyll en erreur) affiché dans un `WKWebView` natif.
- **Fausses détections Shake lors du déplacement de fenêtres** : corrigé en vérifiant `NSPasteboard(name: .drag).changeCount` + types supportés.
- **Conflit aimantation bords avec macOS Window Tiling** : remplacé par le bouton dédié `⇤`/`⇥` dans l'en-tête.

## 💡 Solutions retenues & Arbitrages techniques
- **Zéro permission Accessibilité** : `NSEvent.addGlobalMonitorForEvents(matching: .leftMouseDragged)` (souris uniquement) + Carbon `RegisterEventHotKey` fonctionnent sans aucune permission système — suppression de `PermissionMonitor.swift` et plus aucune manip à refaire après MAJ.
- **Compatibilité macOS 14+** : cible abaissée à `.macOS(.v14)` avec `#available(macOS 26.0, *)` pour `.glassEffect` et fallback `.ultraThinMaterial`.
- **Parcours d'installation intégré dans l'app** : pas de `.pkg` séparé ni de Lisez-moi HTML dans le DMG.

## 🚫 Pistes écartées & Refus de Djaps
- **Pas de fichier "Lisez-moi" dans le DMG** (jugé nul — remplacé par l'assistant intégré dans l'app).
- **Pas d'ouverture du client Mail (`mailto:`)** pour le feedback (remplacé par le formulaire Web3Forms intégré).
- **Pas d'aimantation automatique au drag sur les bords d'écran** (conflit avec le Window Tiling natif macOS — remplacé par le bouton dédié `⇤`/`⇥`).
- **Pas d'ouverture d'étagère vide au reboot / après MAJ**.
- **Pas de version Windows pour l'instant** (aucun testeur Windows sous la main).
- **Ne pas écraser l'app locale lors des releases** (`--no-install` pour tester l'auto-updater).

## ⚠️ Points de vigilance pour le futur
